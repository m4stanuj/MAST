# M4ST Ecosystem

M4ST is the main local-first AI operator project by Mast Anuj. Supporting repositories should be described as modules, adapters, or proof surfaces, not as separate competing brands.

## Repository Map

| Public name | Role |
|---|---|
| M4ST | Local-first AI operator for MCP tools, agents, routing, memory, browser automation, and verified workflows |
| M4ST model router | Task-aware free/local-first model fallback layer |
| M4ST MCP workspace | Portable MCP configuration and workspace-control layer |
| M4ST prompt reuse cache | Repeated-prompt reuse and cost-reduction module |
| M4ST security workflow | Authorized OSINT and defensive research workflow |
| LeadSniper | Public-signal lead discovery and outreach-preparation workflow |
| M4ST portfolio | Public proof surface for projects, demos, and documentation |

## How The Pieces Fit

```text
user request
  -> M4ST context and safety policy
  -> MCP tools and skills
  -> task-aware routing
  -> prompt reuse cache when useful
  -> browser/file/research workflow
  -> verification and proof artifact
```

## Positioning

Public copy should keep the ecosystem compact:

- one M4ST identity
- practical working capabilities
- clear safety boundary
- proof before hype
- Mast Anuj as creator/operator

## Release Discipline

Every public repo should keep:

- clear README
- no secrets
- no private contact details
- no exaggerated claims
- working setup or proof command
- concise safety boundary
